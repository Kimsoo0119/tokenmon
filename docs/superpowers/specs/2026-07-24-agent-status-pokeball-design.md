# 에이전트 상태 몬스터볼 연출 설계

## 목적

터미널에서 Claude Code 에이전트가 **작업 중 / 완료 / 답변 대기** 상태일 때
펫이 몬스터볼 연출로 상태를 보여준다.

## 연출 (v2: 볼은 순간 이벤트, 펫은 항상 밖)

| 이벤트 | 연출 |
|---|---|
| `start` (작업 시작) | 펫 평소 모습 유지. 말풍선 "프로젝트 · 작업 시작" (+작업 세션 수). 펫 옆에 ×N 배지 |
| `done` (작업 완료) | 포획 성공 시퀀스(~2.5초): 볼이 날아와 명중 → 펫 빨려 들어감 → 볼 흔들 → 딸깍! → 터지며 펫 소환 + "작업 완료!" |
| `waiting` (답변 대기) | 포획 실패 시퀀스: 볼이 날아옴 → 펫 탈출(놓침!) → 펫 스킬 시전(돌진 모션+플래시) + "답변을 기다리고 있어요!" |

- 연출이 겹치면 진행 중 시퀀스는 끝까지 재생, 뒤 이벤트는 말풍선만 갱신.
- 볼은 상주하지 않으므로 볼 클릭 복귀는 없음.

### 다중 세션

이벤트의 `session`(Claude Code `session_id`)으로 작업 중인 세션 집합을 유지.
작업 중 세션이 1개 이상이면 펫 옆에 ×N 배지 표시(작업 중 인디케이터 겸용).
`waiting`은 일회성 알림. 이벤트 없이 30분 지난 세션은 자동 제거(1분 주기).

## 말풍선 스타일

기존 다크 말풍선 스타일(별도 창 bubble.html)을 그대로 사용한다. 배지도 같은 톤.
(도트/픽셀 대화창 스타일도 시안으로 검토했으나 가시성이 낮아 기존 스타일 유지)

## 이벤트 형식

`events.jsonl` 한 줄: `{"type":"start"|"done"|"waiting","message":"...","session":"...","project":"..."}`.
`type`이 없거나 모르는 값이면 기존 알림(`notify`)으로 처리 — 하위 호환 유지.
`project`(cwd 폴더명)는 말풍선에 어느 프로젝트 이벤트인지 표시하는 데 쓴다.

## 연결

- Claude Code 훅 (`~/.claude/settings.json`):
  `UserPromptSubmit`→start, `Stop`→done, `Notification`→waiting.
- Codex는 `config.toml`의 `notify`로 done만 연결 가능. 이번엔 Claude Code 위주.

## 구현

- `src/events.js`: 이벤트 파싱 (기존, 변경 없음). 테스트 포함.
- `src/main.js`: watchEvents → `agent-event` IPC (기존, 변경 없음).
- `src/pet/pet.html`/`pet.js`: 볼 절대배치 + 던지기/명중/흔들림/딸깍/소환/탈출 시퀀스,
  ×N 배지, 세션 카운트. 말풍선은 별도 창(bubble.html)으로 IPC 전송.
- `assets/`: 몬스터볼 스프라이트.
